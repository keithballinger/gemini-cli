# Gemini HUD User Guide

## Welcome to Gemini HUD

Gemini HUD transforms your AI coding assistant into a sleek, gaming-inspired overlay that floats above your work. Think of it as your AI co-pilot that's always there but never in the way.

## Getting Started

### First Launch
1. Open Gemini HUD from your Applications folder or press `⌘+Shift+G`
2. The HUD will appear as a semi-transparent overlay
3. Complete the quick setup:
   - Choose your transparency level (50-90%)
   - Set your preferred position (top, bottom, or floating)
   - Configure your activation hotkey

## Core Features

### 1. Always-On Overlay
- **Transparency Control**: Scroll while holding `⌘` to adjust opacity
- **Click-Through Mode**: Press `⌘+Shift+T` to make HUD click-through
- **Smart Hiding**: Automatically fades when you haven't interacted for 30 seconds

### 2. Hot Corners
Move your cursor to screen corners for quick actions:
- **Top-Left**: Toggle voice input
- **Top-Right**: Show stats dashboard
- **Bottom-Left**: Open tool palette
- **Bottom-Right**: Access conversation history

### 3. Voice Input
- **Activation**: Press and hold `Space` while HUD is focused
- **Visual Feedback**: Animated waveform shows input levels
- **Commands**: Say "Hey Gemini" followed by your request
- **Dictation Mode**: Double-tap `Space` for continuous dictation

### 4. Visual Tool Palette
Hover over the left edge to reveal tools:
- 📁 **File Operations**: Browse, read, edit files
- 🔧 **Shell Commands**: Execute with visual feedback
- 🌐 **Web Tools**: Search and fetch with previews
- 💾 **Memory**: Save and recall information
- 🔌 **MCP Servers**: Connected external tools

### 5. Stats Dashboard
Your coding session visualized:
- **Token Usage**: Animated progress bars
- **Response Time**: Real-time latency graph
- **Tool Calls**: Visual activity timeline
- **Efficiency Score**: Gamified productivity metrics

## Keyboard Shortcuts

### Global Hotkeys
- `⌘+Shift+G`: Show/Hide HUD
- `⌘+Shift+N`: New conversation
- `⌘+Shift+R`: Resume last conversation
- `⌘+Shift+V`: Toggle voice input

### HUD Controls
- `⌘+↑/↓`: Navigate conversation history
- `⌘+Enter`: Execute command
- `⌘+K`: Clear current conversation
- `⌘+/`: Show command palette
- `⌘+1-9`: Quick tool selection
- `Esc`: Minimize HUD to menu bar

## Advanced Features

### Gesture Controls
- **Two-finger swipe up**: Show full conversation
- **Two-finger swipe down**: Minimize to compact mode
- **Pinch**: Zoom in/out of conversation
- **Three-finger tap**: Quick checkpoint save

### Visual Modes

#### Compact Mode
Minimal single-line input, perfect for quick commands

#### Extended Mode
Full conversation view with syntax highlighting

#### Focus Mode
Dims everything except HUD for distraction-free coding

### Tool Approval Flow
When Gemini needs to execute tools:
1. **Visual Alert**: Tool icon pulses in the palette
2. **Preview Panel**: Shows what will be executed
3. **Quick Approve**: Press `Y` or click checkmark
4. **Deny**: Press `N` or click X
5. **Always Allow**: Hold `⌘` while approving

### Conversation Checkpoints
- **Auto-save**: Every 10 messages
- **Manual Save**: `⌘+S` with custom name
- **Visual Timeline**: Scrub through checkpoints like video
- **Branching**: Create alternate conversation paths

## Tips & Tricks

### Power User Features
1. **Command Chaining**: Use `&&` to run multiple commands
2. **Snippet Expansion**: Type shortcuts like `gst` → `git status`
3. **Quick Files**: Drag files onto HUD to add context
4. **Screenshot Mode**: `⌘+Shift+S` to capture and analyze

### Productivity Boosters
- Enable **Focus Assist** to queue non-urgent tool approvals
- Use **Voice Macros** for repetitive tasks
- Set up **Project Profiles** with custom settings per codebase
- Enable **Smart Suggestions** based on your coding patterns

## Troubleshooting

### Common Issues
- **HUD not appearing**: Check Accessibility permissions in System Settings
- **Voice not working**: Ensure microphone access is granted
- **Performance issues**: Try disabling GPU acceleration
- **Click-through problems**: Reset with `⌘+Shift+R`

### Support
- **Help Center**: Press `⌘+?` within HUD
- **Report Issues**: `⌘+Shift+B` to file bug report
- **Community**: Join our Discord for tips and tricks

## Privacy & Security

- **Local Processing**: Voice transcription happens on-device
- **No Screenshots**: HUD doesn't capture your screen content
- **Secure Storage**: Conversations encrypted with your keychain
- **Incognito Mode**: `⌘+Shift+I` for temporary sessions
