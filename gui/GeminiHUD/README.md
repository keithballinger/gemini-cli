# Gemini HUD

Native macOS overlay interface for Gemini CLI.

## Development

### Requirements
- macOS 13.0+
- Xcode 15.0+
- Swift 5.9+

### Building
```bash
make build
```

### Testing
```bash
make test
```

### Running
```bash
make run
```

### Linting
```bash
make lint
```
