# Gemini CLI

[![Gemini CLI CI](https://github.com/google-gemini/gemini-cli/actions/workflows/ci.yml/badge.svg)](https://github.com/google-gemini/gemini-cli/actions/workflows/ci.yml)

![Снимок экрана Gemini CLI](./docs/assets/gemini-screenshot.png)

Этот репозиторий содержит Gemini CLI, инструмент командной строки для рабочих процессов с ИИ, который подключается к вашим
инструментам, понимает ваш код и ускоряет ваши рабочие процессы.

С помощью Gemini CLI вы можете:

- Запрашивать и редактировать большие кодовые базы в пределах и за пределами контекстного окна Gemini в 1 миллион токенов.
- Создавать новые приложения из PDF-файлов или эскизов, используя мультимодальные возможности Gemini.
- Автоматизировать операционные задачи, такие как запросы к pull request'��м или обработка сложных rebase'ов.
- Использовать инструменты и серверы MCP для подключения новых возможностей, включая [создание медиа с помощью Imagen,
  Veo или Lyria](https://github.com/GoogleCloudPlatform/vertex-ai-creative-studio/tree/main/experiments/mcp-genmedia)
- Обосновывать свои запросы с помощью инструмента [Google Search](https://ai.google.dev/gemini-api/docs/grounding),
  встроенного в Gemini.

## Быстрый старт

1. **Предварительные требования:** Убедитесь, что у вас установлена [Node.js версии 20](https://nodejs.org/en/download) или выше.
2. **Запустите CLI:** Выполните следующую команду в вашем терминале:

   ```bash
   npx https://github.com/google-gemini/gemini-cli
   ```

   Или установите его с помощью:

   ```bash
   npm install -g @google/gemini-cli
   gemini
   ```

3. **Выберите цветовую тему**
4. **Аутентификация:** При появлении запроса войдите в свою личную учетную запись Google. Это предоставит вам до 60 запросов к модели в минуту и 1000 запросов к модели в день с использованием Gemini.

Теперь вы готовы использовать Gemini CLI!

### Используйте ключ API Gemini:

API Gemini предоставляет бесплатный уровень с [100 запросами в день](https://ai.google.dev/gemini-api/docs/rate-limits#free-tier) с использованием Gemini 2.5 Pro, контролем над используемой моделью и доступом к более высоким лимитам запросов (при платном плане):

1. Сгенерируйте ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. Установите его как переменную окружения в вашем терминале. Замените `YOUR_API_KEY` на ваш сгенерированный ключ.

   ```bash
   export GEMINI_API_KEY="YOUR_API_KEY"
   ```

3. (Необязательно) Обновите ваш проект API Gemini до платного плана на странице ключа API (это автоматически разблокирует [лимиты запросов уровня 1](https://ai.google.dev/gemini-api/docs/rate-limits#tier-1))

Для других методов аутентификации, включая учетные записи Google Workspace, см. руководство по [аутентификации](./docs/cli/authentication.md).

## Примеры

После запуска CLI вы можете начать взаимодействовать с Gemini из вашей оболочки.

Вы можете начать проект из нового каталога:

```sh
cd new-project/
gemini
> Напиши мне бота для Discord на Gemini, который отвечает на вопросы, используя файл FAQ.md, который я предоставлю
```

Или работать с существующим проектом:

```sh
git clone https://github.com/google-gemini/gemini-cli
cd gemini-cli
gemini
> Дай мне сводку всех изменений, которые были внесены вчера
```

## Популярные задачи

### Изучение новой кодовой базы

Начните с `cd` в существующий или только что клонированный репозиторий и запустите `gemini`.

```text
> Опиши основные части архитектуры этой системы.
```

```text
> Какие механизмы безопасности здесь действуют?
```

### Работа с существующим кодом

```text
> Реализуй черновой вариант для задачи GitHub #123.
```

```text
> Помоги мне перевести эту кодовую базу на последнюю ве��сию Java. Начни с плана.
```

### Автоматизация ваших рабочих процессов

Используйте серверы MCP для интеграции ваших локальных системных инструментов с вашим корпоративным пакетом для совместной работы.

```text
> Сделай мне презентацию, показывающую историю git за последние 7 дней, сгруппированную по функциям и членам команды.
```

```text
> Сделай полноэкранное веб-приложение для настенного дисплея, чтобы показывать наши самые обсуждаемые задачи на GitHub.
```

### Взаимодействие с вашей системой

```text
> Преобразуй все изображения в этом каталоге в png и переименуй их, используя даты из данных exif.
```

```text
> Организуй мои PDF-счета по месяцам расходов.
```
